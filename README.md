## Tutorial Summary

### Week 1 – Getting Started with GitHub Codespaces

**Main Topics:**

* GitHub Codespaces
* Basic Java programming
* Git and GitHub workflow

**Key Learning:**

I learned how to work with GitHub Codespaces and create basic Java programs. I also became familiar with fundamental Git commands such as `git init`, `git status`, `git add`, `git commit`, and `git push`.

The Java programs included `HelloWorld.java` and `StudentGrade.java`, which helped me understand the basic process of writing, running, and checking Java program output.

---

### Week 2 – Classes and Objects

**Main Topics:**

* Classes
* Attributes
* Constructors
* Methods
* Objects

**Key Learning:**

I learned how to create Java classes with attributes and methods and how to use constructors to initialize objects. I also learned how to create objects using the `new` keyword.

This tutorial helped me understand the relationship between classes and objects and introduced me to the basic structure of Object-Oriented Programming.

---

### Week 3 – Inheritance and Polymorphism

**Main Topics:**

* Inheritance
* Parent and child classes
* `super()`
* Method overriding
* Polymorphism

**Key Learning:**

I learned how to create a parent `Person` class and extend it to create `Student` and `Lecturer` classes. I also learned how to use `super()` and override methods using `@Override`.

This helped me understand how inheritance can support code reuse and how different classes can provide different implementations of the same method.

---

### Week 5 – Encapsulation

**Main Topics:**

* Encapsulation
* Data hiding
* `private` variables
* Getters and setters

**Key Learning:**

I learned how encapsulation protects data by restricting direct access to variables. I used private variables together with public getters and setters to control how information is accessed and modified.

This tutorial helped me understand the importance of maintaining data integrity within a class.

---

### Week 6 – Employee and Lecturer Inheritance

**Main Topics:**

* Inheritance
* `protected` access modifier
* Parent and child classes
* "Is-a" relationship

**Key Learning:**

I reinforced my understanding of inheritance by creating an `Employee` class and extending it to create a `Lecturer` class.

I also learned about the `protected` access modifier and how it allows subclasses to access inherited attributes while maintaining controlled access.

---

### Week 7 – Abstraction and Appliance Management

**Main Topics:**

* Abstraction
* Abstract classes
* Abstract methods
* Subclasses

**Key Learning:**

I learned how to create an abstract `Appliance` class and implement specific appliance classes such as `WashingMachine`, `Television`, `Microwave`, and `AirConditioner`.

This tutorial helped me understand how abstraction can define a common structure for different classes while allowing each subclass to provide its own implementation.

---

### Tutorials 8–9 – Task Manager and File I/O

**Main Topics:**

* `ArrayList`
* `Scanner`
* File I/O

The Task Manager application allowed me to combine several Java concepts into a practical application. I learned how to store tasks using collections, receive user input, write information to a text file, and read saved information.

I also learned the importance of exception handling when working with files and other operations that may produce errors.

### Tutorial 10 – Quiz Battle GUI

## How to Run the Projects

### Using GitHub Codespaces

1. Open this repository on GitHub.
2. Open the repository using GitHub Codespaces.
3. Navigate to the required project folder.
4. Open the Java source files.
5. Compile and run the required Java program.
6. Follow the instructions provided by the program.

### Using a Local Java Development Environment

1. Clone or download the repository.
2. Open the required project folder in a Java-supported IDE or development environment.
3. Make sure Java is installed and configured correctly.
4. Open the required `.java` file.
5. Compile and run the program.
6. Follow the program instructions.

The projects include both console-based applications and a graphical user interface application.
